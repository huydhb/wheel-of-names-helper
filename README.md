# Hack Wheel of Names Extension 🎯

Tiện ích mở rộng Chrome (Manifest V3) hỗ trợ điều khiển kết quả vòng quay **Wheel of Names**, **Wheel Random**, **Spin the Wheel**.

## 🌟 Tính năng chính
- 🎯 **Điều khiển kết quả**: Thiết lập danh sách tên ưu tiên cần trúng theo thứ tự.
- 🧩 **Giao diện Popup góc trên**: Cửa sổ điều khiển tích hợp trực tiếp dưới biểu tượng Extension trên thanh công cụ.
- ⚡ **Tự động khôi phục**: Lưu cấu hình tên mục tiêu tự động, duy trì trạng thái khi tải lại trang (F5).
- 🛡️ **Tuân thủ CSP**: Tách rời script chính (`inject.js`) chuẩn Manifest V3.

## 📦 Cài đặt
1. Tải repository này về máy hoặc clone qua git:
   ```bash
   git clone https://github.com/huydhb/wheel-of-names-extension.git
   ```
2. Mở trình duyệt Chrome / Edge và truy cập `chrome://extensions/`.
3. Bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
4. Nhấn **Tải tiện ích đã giải nén (Load unpacked)** và chọn thư mục `wheel-of-names-extension`.
5. Mở trang [Wheel of Names](https://wheelofnames.com/) và bấm vào icon Extension để sử dụng!
